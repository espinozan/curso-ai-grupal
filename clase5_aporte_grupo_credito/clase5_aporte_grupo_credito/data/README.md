# Datos

Colocar aquí `dataset_credito.csv` si no se utiliza la ruta de la cátedra:

```text
data/dataset_credito.csv
```

El proyecto también intenta encontrar automáticamente la ruta usada en la clase:

```text
../modulo_3/dataset_credito.csv
```

No se incluye el CSV original en el repositorio para evitar distribuir innecesariamente registros individuales de un dataset de crédito.
